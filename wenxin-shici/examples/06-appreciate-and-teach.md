# 示例 06：古诗赏析与入声字教学（脚本联动）

本示例展示两项独立核心能力：**六维古诗文赏析**与**基于脚本实操的格律教学**。

---

## 一、赏析示范：杜甫《登高》

> **用户**：读到杜甫的《登高》，觉得震撼但说不清它妙在哪里，能给我细细拆解一下吗？

### 原文与格律核验

先以 `scripts/dupcheck.py --title 登高` 核实全文，再以 `scripts/meter.py check` 校其声律（平水韵 上平十灰，仄起首句入韵，全诗 **合律，错误 0**）：

> 风急天高猿啸哀，渚清沙白鸟飞回。
> 无边落木萧萧下，不尽长江滚滚来。
> 万里悲秋常作客，百年多病独登台。
> 艰难苦恨繁霜鬓，潦倒新停浊酒杯。

（脚本同时给出两条有趣观察：其一，平水韵上平十灰“哀、回、来、台、杯”在今音分属开韵与微韵，故现代朗读会感到二、八句微有收音变化；其二，第五句“客”为入声字，不可误按今音作平。）

### 章法结构（起 → 展 → 转深 → 结穴）

- **首联（破题定调）**：十四字连排风、天、猿、渚、沙、鸟六景，字字有情色（急、高、哀、清、白、回），如电影冷调全景推入，将天地肃杀与江风中盘旋难进的孤鸟立在眼前。
- **颔联（展开撑阔）**：视界骤然放至天地无穷。“无边落木”写空间与生命的有限凋零，“不尽长江”写宇宙时间的浩荡奔流。人夹在有限与无限之间，全诗张力由此绷紧。
- **颈联（由景入身，转深）**：宋人罗大经评此联“一联含八意”——空间“万里”与“常作客”（漂泊），时间“百年”与“多病”（垂暮），再加“悲秋”与“独登台”。空间之阔与岁月之重，此刻全压在一个人肩头。
- **尾联（收束落穴）**：家国艰难与满头白发并至，最后收在一件极具体的小事上——因病连“浊酒”都不得不“新停”。杜甫的沉郁不在叫苦，而在连借酒浇愁的出口也被生活封死后的实录。

### 意象与炼字

- **“落木”对“长江”**：不言“落叶”而言“落木”，木字硬朗萧瑟，声响亦沉；“萧萧下”之坠落与“滚滚来”之奔涌形成俯仰动态对撞。
- **“鸟飞回”**：不是轻快飞翔，而是在急风中盘旋兜转——恰好是诗人一生在乱世辗转难归的投影。

### 用典溯源与诗史定位

全诗以白描直取天地之气，“猿啸哀”暗接《水经注》“猿鸣三声泪沾裳”，“萧萧”呼应《楚辞》悲秋之音，而无半字掉书袋。胡应麟《诗薮》推之为“古今七言律第一”，正因它把四联对仗（此作实则首、颔、颈甚至尾联皆有对意）全化作一气奔涌的生命实感，是盛唐转中唐之际沉郁顿挫的顶峰。

## 二、教学示范：普通话里没有入声，怎么辨认入声字？

> **用户**：学写近体诗和填词总在入声字上踩坑，有没有既讲清原理又能马上实操判断的方法？

### 1. 原理：为何用普通话读古诗会误判？

中古汉语分**平、上、去、入**四声。入声字发音短促，以塞音韵尾（`-p / -t / -k`）收尾，在**平水韵中一律归仄声**（词林正韵第 15–19 部亦单独成韵）。后来普通话语音演变，入声消失并分别派入阴平、阳平、上声、去声四调。因此许多今音读**一、二声（阴平/阳平）**的字，在古诗格律里实打实是**仄声**——比如李白《静夜思》里的“月”（入声归去，今亦仄），而《登鹳雀楼》里的“**白**日依山尽”的“白”（bái，今阳平实为入声仄）、“更上**一**层楼”的“一”（yī，今阴平实为入声仄），若用普通话算平仄就会把整首诗判反。

### 2. 三条日常规律＋一条必防误区

1. **方言留声法**：懂粤语、闽南语、客家话、潮汕话或吴语者，念出声短促顿挫、带塞音收尾的便是入声（如粤语“白” `baak6`、“一” `jat1`）。
2. **普通话声母强信号**：凡普通话读**阳平（二声）**且声母为 **`b、d、g、j、zh、z`** 的字，绝大多数是古入声字：
   - `b`：白、薄、别、拔、伯
   - `d`：独、读、毒、笛、敌、德
   - `g`：国、格、阁、革、隔
   - `j`：急、及、极、集、菊、局、绝
   - `zh`：竹、逐、烛、直、值、折
   - `z`：族、卒、杂、昨、则
3. **常见韵母辅助**：今读阳平且韵母为 `-ie`（别、铁、灭、节）、`-ue`（学、绝、雪、觉、越）、单韵母 `-e`（德、色、客、黑、特）的字多属入声（例外如 `m/n/l/r` 声母多非入声，或“咱”非入声）。
4. **注意破除一条错误口诀**：网上流传“整体认读韵母 `-i`（zhi/chi/shi/ri/zi/ci/si）都不是入声”是**错的**——像**十、石、实、识、日、质、直、尺、赤、室**恰恰都是铁板钉钉的古入声字！

### 3. 实操最稳妥一招：直接用脚本一秒筛出

记规律只作初筛，动笔遇不准的字或成稿自检时，直接跑本技能的入声过滤命令即可（以《登高》首联为例）：

```bash
$ python scripts/meter.py lookup --rusheng "风急天高猿啸哀，渚清沙白鸟飞回"
急 ●  ★[入声·今读平，近体须作仄：入声十四缉]
     平水韵：入声十四缉（仄）
     词林正韵：第17部入    新韵：齐韵（12）平
白 ●  ★[入声·今读平，近体须作仄：入声十一陌]
     平水韵：入声十一陌（仄）
     词林正韵：第17部入    新韵：开韵（4）平、波韵（2）平
```

脚本直接用 `★` 标出了最易踩坑的“今读平、古入声”字；填《满江红》《念奴娇》等常押入声韵的词牌时，再用 `python scripts/meter.py rhymes <入声韵目>` 即可一次列出可靠入声韵脚，再也不必死背数百字表。
