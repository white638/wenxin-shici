# 风格流派总览与模仿心法

读风格专篇，主要是为了**听出那种声音与呼吸**——看它的基调、句法骨架与经典例句，而不是边写边照抄现成字眼。

## 二、九大流派与历代特殊诗风标签

问答与赏析时常需准确锚定流派坐标：

- **九大古典流派脉络**：① 田园诗派（陶渊明→王孟）｜② 边塞诗派（王之涣/王昌龄/高适/岑参）｜③ 浪漫主义（屈原→李白→李贺）｜④ 现实主义（杜甫→白居易/张籍）｜⑤ 婉约词派（温庭筠/柳永/晏氏父子/秦观/周邦彦/李清照/纳兰性德）｜⑥ 豪放词派（苏轼/辛弃疾）｜⑦ 山水诗派（谢灵运/谢朓→王维）｜⑧ 咏史怀古（杜甫/杜牧/刘禹锡/辛弃疾）｜⑨ 唐宋八大家古文（韩愈/柳宗元/欧阳修/三苏/王安石/曾巩）。
- **历代重要诗风标签**：
  - **建安风骨**（汉末三曹七子：慷慨悲凉，直面时代与生命烈度）
  - **正始之音**（阮籍、嵇康：玄思与深藏的忧愤）
  - **永明体**（南朝齐谢朓、沈约：声律四声觉醒，近体先声）
  - **元和体**（中唐元稹、白居易：长篇叙事与通俗诗风）
  - **西昆体**（北宋初杨亿等：效法李商隐，对偶用典精丽）
  - **江西诗派**（北宋末黄庭坚等：“点铁成金”“脱胎换骨”，讲究奇峭拗句与字字有来历）
  - **诚斋体**（南宋杨万里：捕捉瞬息鲜活生活，活泼自然）
  - **神韵派**（清初王士禛：崇尚含蓄蕴藉、言有尽而意无穷）
  - **性灵派**（清中叶袁枚：力矫拟古僵化，直抒真性情）

## 三、风格模仿三部曲（学神不抄皮）

当用户要求“模仿某某诗人写一首”时，**绝不复制他的招牌词汇拼盘**（例如写李白就硬凑“明月、银鞍、青天、美酒”），而按三步重构：

| 目标诗人 | 核心美学 | 句法与选材抓手 |
|---|---|---|
| **李白** | 抛弃雕琢感的气势与腾挪 | 少工对、少冷僻典、多流水句与强动词、用大时空跳跃 |
| **杜甫** | 字字沉实、层层收紧的张力 | 精炼动词、中二联求工对、从天地落向一身一盏酒 |
| **王维** | 人在画外、静中有响 | 多白描、少用“我”与直接抒情词、以光线和微声写情绪 |
| **陶渊明** | 似未用力而全篇浑然 | 减省辞藻、聚焦一两个极日常的物象、结尾淡然收住 |
| **李商隐** | 幽微绵密、不说破 | 设问句、冷暖意象交错、深层用典留出多重解读空间 |
| **苏轼** | 大开大合后落回微小真实 | 上半放眼天地古今，下半收归眼前人、茶与一念清欢 |
| **李清照** | 以至白之语说至深之痛 | 巧用叠字与细节小器物（帘、舟、盏），白描中见凄紧 |
| **辛弃疾** | 把史书典故当剑戟使 | 典故密而有锋芒，善用“休问、莫舞、凭谁问”等呼告领字 |

**三步操作**：① 提取该诗人的核心审美机制 → ② 抓出他的典型句式节奏与视角位置 → ③ 装入**用户本次自己的真实场景和意象**重新铸句。
