# 对联、藏头与嵌字诗

对联（楹联）是将对仗推向独立的文学形式；藏头、藏尾、嵌字诗与嵌名联则是将特定字词（人名、店名、祝语）依序嵌入诗联之中，最常用于春联、寿宴、婚嫁、乔迁、开业、周年庆或个人纪念。

---

## 一、对联

### 1. 五条基本规则

1. **字数相等，断句相同**：上下联总字数及各分句字数须一一对应。
2. **词性相当、结构相称**：名对名、动对动、形对形、数对数、虚对虚；主谓、动宾、偏正结构对应（工对尤佳，宽对自然为尚；亦可用流水对、借对、当句对）。
3. **仄起平收（最硬底线）**：上联末字必须是**仄声**，下联末字必须是**平声**。
4. **节奏点平仄相反**：二、四、六字节奏点上下联宜平仄相反，句内交替；多分句长联讲究“马蹄韵”（上下联各分句句脚如平仄仄平平仄交替，最终上仄下平）。名联偶有宽放（如林则徐“海纳百川……壁立千仞……”第二字同仄），但句脚仄起平收不可松动。
5. **内容相关且忌合掌、无意重字**：上下联同写一事或互为映衬，切忌同义废话；除非有意重字对应（如“风声雨声读书声，声声入耳；家事国事天下事，事事关心”），上下联同位或异位应避无意重字。

### 2. 常见场合对联要点

| 联类 | 重点 | 避忌 |
|---|---|---|
| **春联** | 辞旧迎新、切合岁次生肖与时令；可配四字横批 | 晦暗不吉字词 |
| **寿联** | 切合年齿雅称（见 [../types/zhusong.md](../types/zhusong.md)）、平生德业；常用松鹤、大椿、南山 | 死、病、老、暮、衰 |
| **婚联** | 两姓之好、琴瑟和鸣、桃夭、可嵌新人姓名 | 离、散、孤、长门、破镜 |
| **挽联** | 称颂逝者风范与生平实事，措辞肃穆沉挚 | 轻佻、谐趣，绝不编造逝者事迹 |
| **行业 / 开业联** | 贴合行业特质，嵌名自然 | 肉麻吹捧与空洞大话 |
| **名胜 / 书房联** | 切合当地山水史迹或言志修身 | 只写空景无人文，或直白说教 |

### 3. 脚本校验与张贴交代

```bash
python scripts/meter.py check --form 对联 "上联；下联"
python scripts/meter.py annotate --feet "长联全文"   # 核查多分句长联马蹄韵句脚
```

脚本检查字数、断句一致性、仄起平收、节奏点平仄相对及同位重字；词性结构对仗与合掌需人工复核。交付时标明上联、下联、横批（并可简注面向大门上右贴/下左贴的传统规制，或依从左到右横批调整）。

## 二、藏头、藏尾、嵌字与嵌名联

### 1. 常见位置

- **藏头**：每句首字连读成句或成名（最常用，4 字写绝句，8 字写律诗，2 字写对联/两句诗，3/5/7 字等非偶数句改写古风或征求用户调字）。
- **藏尾**：每句末字连读（受韵部限制极大，必先查这几字是否可同押一韵，否则极难自然）。
- **嵌字（诗钟七格）**：一字凤顶、二字燕颔、三字鸢肩、四字蜂腰、五字鹤膝、六字凫胫、七字雁足。
- **嵌名联**：将双字名分别嵌入上下联相同位次，如分嵌每句第一字、或“鹤顶格/雁足格”。

### 2. 藏头诗写活四步法

1. **先查平仄与韵部**：跑 `python scripts/meter.py lookup <要藏的字>`。**七言近体首字均属“中”（可平可仄），远比五言好藏**（五言 `B` 句首字用仄须“孤平拗救”）。
2. **先立统一主旨**：藏头诗最大死穴是“每句各说各话、只为凑首字”。必先定清整首诗要祝贺/表达什么，让每个字落在这条主线上。
3. **化解难藏虚字或现代词**：
   - 如“快、乐、爱、的、你”难单独入古诗时，尽量化入古今通词（“乐事”“快意”“爱此”“爱看”），或将整首定为清浅通俗/闲适风格。
   - **绝不擅自增删或改换用户指定要藏的字**；确实因语义或韵部难以自然入律时，先与用户商量能否调字，或改用 `--loose` 写成古风。
4. **严格验律并交代权衡**：跑 `meter.py check` 过检；若因极硬的嵌字要求导致个别名句气韵略有妥协，交付时坦诚说明并突出已藏之字（加粗或附注“藏头：XXXX”）。
