# 古体诗：古风、歌行、乐府

古体诗形成于近体定型之前，唐及后世亦代有佳作。它不守粘对、句数不限、可换韵、可杂言，最宜承载奔涌长气、完整叙事与太白体浪漫豪情。

## 1. 古体 vs 近体一览

| 维度 | 古体诗（五古 / 七古 / 歌行 / 乐府） | 近体诗（绝句 / 律诗 / 排律） |
|---|---|---|
| 句数与字数 | 不限，可四言、五言、七言或长短杂言 | 绝句 4 句、律诗 8 句、排律偶数句；限五/七言 |
| 平仄与粘对 | 不受近体粘对束缚，忌通篇皆律句 | 严守平仄谱、粘对、避孤平与三平尾 |
| 押韵 | 可平韵、可仄韵（上去通押），可分段换韵 | 限押平声韵，一韵到底（首句可借邻韵） |
| 对仗 | 完全自由 | 律诗中二联（排律中间各联）必须对仗 |
| 代表名作 | 李白《将进酒》、杜甫《石壕吏》、岑参《白雪歌》、陶渊明《归园田居》 | 杜甫《登高》、王维《山居秋暝》、李白《早发白帝城》 |

## 2. 常见体类与适用场合

- **五言古诗**：源出《古诗十九首》与陶渊明、杜甫“三吏三别”，最宜质朴叙事、田园闲适、哲理沉思。
- **七言古诗与歌行**：题名常带“歌、行、引、吟、谣、曲”，长于节奏奔放、时空跳跃（如李白《将进酒》、岑参《白雪歌送武判官归京》）。
- **乐府旧题**：沿用《行路难》《关山月》《长相思》《白马篇》《少年行》等旧题时，内容应与旧题主旨相通。
- **柏梁体**：七言每句押韵（杜甫《饮中八仙歌》），适合热闹叙人。
- **杂言 / 骚体**：三、五、七、九言错落，或夹“兮”字（如“大鹏飞兮振八裔”）。
- **实用宽松场**：定场诗、幽默打油诗也常用七言古风（脚本支持 `--form 古风` 或 `--loose`）。

## 3. 押韵与“古调”的讲究

- **换韵节奏**：常见四句一换，或随情绪/场景推进而换；平韵与仄韵交替（如先抑后扬、或盛转急切）最出起伏感。**换韵处新段第一句通常入韵**，让读者听出“转调了”。
- **仄韵押法**：古风允许上声、去声通押及宽泛邻韵通押，入声一般单独押，更显短促激越。
- **避“拆散律诗”之病（古调）**：
  - 近体严禁的**三平尾、三仄尾、孤平**，在古体诗里反而是构成古调的关键声响（七古平韵常以三平尾收句，显得雄浑苍古）。
  - 押平韵时，不押韵的出句句末宜落仄声，衬出韵脚响亮。
  - 若通篇五/七言几乎全是标准近体律句，读起来就像“写坏了粘对的律诗”。运行脚本时，若 5/7 言句过多合规律句，`meter.py` 会主动发出预警。

## 4. 章法与脚本校验

- **章法**：歌行起势宜猛（常用呼告与大意象，如“君不见”）；一个韵段推进一层意思或一场画面；中段可叙事、神游、插对话；结尾常见高扬收束、陡然戛止或宕开余韵。太白体长篇写法专见 [../styles/taibai.md](../styles/taibai.md)。
- **脚本检查**：
  `python scripts/meter.py check --form 古风 "全诗"`
  脚本会按词林正韵大部近似检查古风换韵与疑似出韵（如单句独押），并在全部五/七言过于接近近体律句时给出 `[通篇律句]` / `[律句偏多]` 提示。
