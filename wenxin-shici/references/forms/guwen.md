# 古文：文以载道，气盛言宜

古文以散句为主体，不强求押韵与通篇对仗，追求“气盛言宜”“辞达而已”——不卖弄辞藻，不用伪古词装腔，以最精准朴素的气脉直指人心。

## 1. 源流与四大坐标

- **先秦两汉基石**：《论语》《孟子》《庄子》的对话理趣，《左传》《史记》的叙事笔法，是后世古文的语言与思想源头。
- **中唐韩柳古文运动**：韩愈、柳宗元力矫六朝浮靡骈风，倡“文以明道”“气盛言宜”——先有充沛真气，言辞自然妥帖（《师说》《马说》《祭十二郎文》《捕蛇者说》《小石潭记》）。
- **北宋温润通达**：欧阳修、苏轼、苏洵、苏辙、王安石、曾巩将古文推向人文化、生活化与议论锋芒（《醉翁亭记》二十一“也”字如泉滴、《岳阳楼记》景情理递进、《记承天寺夜游》八十五字写尽旷达、《六国论》判词开篇）。
- **明清日常小品**：归有光《项脊轩志》以一株手植枇杷树写尽家常与永诀，不用一句哭天抢地而字字令人断肠。

## 2. 五种实用体类与章法骨架

| 体类 | 经典代表 | 章法脉络 | 适用场景 |
|---|---|---|---|
| **记**（游记 / 室记 / 亭记） | 《岳阳楼记》《项脊轩志》《记承天寺夜游》 | 缘由 → 写景叙事 → 借景生情 → 议论或收于余味 | 游历纪念、书房迁居、某处旧物怀人 |
| **说**（托物 / 说理） | 《爱莲说》《马说》《师说》 | 立核心比喻或论断 → 对比论证 → 深化点题 | 阐发观点、托物寄怀、劝学育人 |
| **论**（政论 / 史论） | 《六国论》《过秦论》 | 判词式破题 → 分层正反论据 → 反诘推深 → 归结鉴戒 | 评史论世、剖析成败得失 |
| **序 / 书**（赠序 / 书信） | 《送东阳马生序》《与山巨源绝交书》 | 交代交谊与缘由 → 叙事共勉 → 抒怀嘱托 | 赠友长信、毕业临别赠言、自述志趣 |
| **祭文 / 悼文** | 《祭十二郎文》 | 闻讯惊痛 → 追忆日常细节 → 问天自悼 → 寄托余念 | 亲友悼亡、深切缅怀（忌空洞官样碑文套话） |

## 3. 写作法度与四大忌

1. **短句立骨，长句推理**：古文的力量大多落在短句下断语（“山不在高，有仙则名”“六国破灭，非兵不利”），长句仅用于因果推演。
2. **虚字精用而有声气**：“之乎者也矣焉哉”贵精不贵多，用对处成文气（如欧阳修《醉翁亭记》），乱塞则是腐酸“伪古文”。
3. **适当“骈散兼行”**：散句之中偶插一对偶句或排比短句（如“不以物喜，不以己悲”），顿生节奏张力，但不必通篇工对。
4. **四大忌**：
   - **忌现代议论文腔**：切勿出现“首先、其次、最后、综上所述、我觉得、正能量”等翻译体与当代白话逻辑词；古文立论口吻宜笃定凝练。
   - **忌情感虚浮泛滥**：慎用“呜呼哀哉”，学归有光把悲欢压在具象细节之下（“庭有枇杷树，吾妻死之年所手植也，今已亭亭如盖矣”）。
   - **忌掉书袋式引经**：引前人语须与下文构成对话与推进，不可引完即止。
   - **忌无骨凑字**：散体虽不限平仄，写完仍须默读或轻诵，剔除拗口拖沓之处；偶用成句或名典时，可用 `python scripts/dupcheck.py --find` 核实引用原文。
