# 改诗、校律与多轮打磨

无论是接手用户已有的诗稿（自写、朋友所作或初稿），还是在创作交付后继续根据用户反馈逐轮打磨，核心铁律只有两条：**尊重原作者本意**，以及**所有改动以脚本实测过检为准**。

---

## 一、改诗五种模式

| 用户诉求 | 模式 | 改动尺度 |
|---|---|---|
| “看看格律对不对 / 哪里出韵” | **纯校律** | 只诊断并给最小改法，不动原作者其余句意 |
| “修得合律 / 调一下平仄” | **只修格律** | 尽量只替换个别字或调序，保留原意与原句骨架 |
| “润色一下 / 改得更传神” | **炼字提升** | 中等幅度，去套语、换动词、理对仗、强收尾 |
| “改成豪放一点 / 学李白” | **换风格** | 较大，保留核心立意与真实素材，重塑语气与句法 |
| “改成七绝 / 这首古风改律” | **换体裁** | 重构，保留立意与细节，按新体裁与新韵重新结篇 |
| “帮我改改”（未明说幅度） | **综合** | 先肯亮点，再修硬伤，视需要提供“微调版 / 精修版”两套方案 |

---

## 二、改诗与校律标准流程

1. **读懂原作**：先判断所属类型（[../types/index.md](../types/index.md)）、立意、写得最好的句子（务必保留）。
2. **先跑脚本摸底**：
   - 近体/古风：`python scripts/meter.py check "原诗"`（或加 `--rhyme xinyun`）
   - 词：`python scripts/meter.py check --form 词:词牌名 "原词"`（或 `--pattern "谱"`）
   - 对联：`python scripts/meter.py check --form 对联 "上联；下联"`
   - 撞句：`python scripts/dupcheck.py "原诗"`
3. **五层诊断（按轻重排序）**：
   1. **格律硬伤**：出韵、失粘、失对、孤平、三平尾、词谱失律、字数不符。
   2. **语病与用典偏差**：字面不通、白话腔入侵、典不贴意或典意相反。
   3. **立意与章法**：立意是否模糊、转折是否生硬、结尾是否无力或沦为说教。
   4. **对仗与画面**：中二联是否合掌或“四言一法”；景物是否孤立罗列缺乏动态呼应。
   5. **字句与听感**：陈词套语（独倚栏杆、泪满襟等）、无意重字、凑韵、韵脚今音跳跃过大。
4. **按模式动手，改后必重跑脚本**，确保零错误方才交付。

## 三、多轮修改协作协议（对已交付稿继续打磨）

当用户对一首刚写完的作品提出“这里读着太轻”“某句好像太熟”“想把某地名放进去”等反馈时：

1. **先复述理解（1–2 句）**：确认用户真正不满意的靶点（例如“我明白，‘吹’字偏轻，想要更有侵入感的秋风；‘独倚栏杆’也确实太熟了”）。
2. **逐点诊断根因并给对策**（常见五类诊因）：
   - **用字力度不够 / 景物静物罗列** → 换精准动词让意象互相作用（如“寒鸦数点斜阳晚”只是两张静照，改为“寒鸦点破苍山晚”便生出飞掠之势）。
   - **套语太熟** → 换成本次情景的具体动作与视野（“独倚栏杆”→“目断云山”）。
   - **典故偏离（典不贴意/越界）** → 宁可删典重写，优先纳入用户给出的**真实地名、物件、细节**（一个真实的“南山苑”胜过任何翻出来的闺怨熟典）。
   - **韵脚今音跳跃感** → 若 `[今音听感]` 提示古韵虽合但今音跨韵母较大，酌情在不损意境处微调韵脚。
   - **用户“说不清哪里怪”** → 给出 2–3 个具体方向（换韵部声情 / 改结句落点 / 调词牌）供选择。
3. **重跑 `meter.py check` 与 `dupcheck.py`** 确认修改后仍严格合律。

## 四、常见格律问题精确修法

| 问题 | 最小改法 |
|---|---|
| **出韵** | 用 `python scripts/meter.py rhymes <韵目>` 另选同韵部字替换韵脚；若难以兼顾文意，宁可改该句或全篇换韵 |
| **失粘 / 失对** | 调整该句第二字（七言兼看四、六字）的平仄；若上下联内部句式刚好颠倒，亦可对调一联内的上下句顺序（律诗中二联须同时重审对仗） |
| **孤平** | 五言将第 1 字（七言第 3 字）换为平声；或用孤平拗救：将五言第 3 字（七言第 5 字）换为平声，构成 `仄平平仄平` |
| **三平尾** | 将五言第 3 字（七言第 5 字）换为仄声 |
| **拗而未救** | 在同联对句的五言第 3 字（七言第 5 字）换用平声相救 |
| **重字** | 删改其中一处为近义字或另一侧面；叠字及有意复沓（如“白日依山尽……欲穷……”无重字，或李白《长相思》有意复字）另当别论 |
| **多音字与义不合** | 按诗意确定真实读音，不合律则换字 |
| **撞句** | 改写连续 5 字撞名篇的片段；有意化用则在注释写明出处 |

## 五、分寸：勿把古绝、拗律和他人诗判成“写错了”

- **不要无中生有挑错**：古风、词、铭赋不按近体律绝判定；按中华新韵写的作品不用平水韵判定（不确定作者所用韵书时，可先问一句或两种都跑一遍分别说明）。
- **名篇变格要如实解释**：如李白《静夜思》是**古绝**，崔颢《黄鹤楼》前四句是入律的**拗律**，王维部分七律有意失粘属于**折腰体**，李清照《声声慢》用入声叠字。校律时要指出它属于哪种传统体格与声律趣味，不要当成“错误”来“改正”。
- **朋友或新手之作**：语气应温厚克制，先肯定写得好的句眼与立意，再谈具体修改建议。

## 六、交付格式

```markdown
**原诗亮点**：一两句点出原作立意或写得最传神的字句。

**诊断要点**
- 〔问题位置与原因，纯校律时可附逐字平仄行 ○ 平 ● 仄 ◐ 多音〕

**修改稿**〔纯校律且用户未要求改写时可略；综合润色可给 1–2 个侧重不同的版本〕

**改动对照**
| 原句 | 改句 | 理由 |
|---|---|---|
| …… | …… | …… |

**格律**：〔脚本复检结论、韵书韵部及多音字说明〕
```
