# 经典意象词典

> 意象是“寄托了情感与记忆的物象”。理解传统意象的“源”与“流”，方能用得准、用得活，既不堆砌也不落俗套。

## 使用原则

1. **一首一主意象群**：绝句 1–2 个，律诗 2–3 个，中长调 3–5 个；其余物象围绕主意象展开。
2. **用户真实意象优先**：用户原话里的具体地名、小物件、天气瞬间，比任何现成古典意象都更有生命力。
3. **翻新胜于套用**：不必写了月亮就是“思故乡”、写了杜鹃就是“啼血”；换个角度（如写杜鹃掠过林梢的影子、写月光斜入工位窗台）立刻出新。
4. **旧意象可入今景**：把月、风、雁、柳、孤灯放进当代城铁、深夜摊档、高楼窗台里，写好动作呼应，便成当代人的古典意境。

## 一、自然天象与山水

### 月
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 思乡怀远 | 同一轮月连接两地时空 | 李白“举头望明月，低头思故乡” |
| 永恒与孤寂 | 月恒而人迁，时间对照 | 张若虚“江畔何人初见月？江月何年初照人？” |
| 清冷高洁 | 世俗之外的精神澄明 | 王维“明月松间照，清泉石上流” |
| 聚散无常 | 圆缺比附人生际遇 | 苏轼“人有悲欢离合，月有阴晴圆缺” |

### 风
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 春风 | 生机、回暖、解冻 | 王安石“春风又绿江南岸” |
| 秋风 / 西风 | 萧瑟、凋零、迟暮 | 杜甫“风急天高猿啸哀”；马致远“古道西风瘦马” |
| 东风 | 春意、造化之力或身外机缘 | 李商隐“东风无力百花残” |

### 水 / 江 / 河
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 时光与历史 | 滚滚东流、浪淘尽英雄 | 苏轼“大江东去，浪淘尽，千古风流人物” |
| 绵长愁绪 | 不绝如春水东流 | 李煜“恰似一江春水向东流” |
| 阻隔遥望 | 隔水相望的可望不可即 | 《诗经》“所谓伊人，在水一方” |
| 生命浩荡 | 无穷尽的时空纵深 | 杜甫“不尽长江滚滚来” |

### 山
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 阻隔艰难 | 关山阻隔，征途失路 | 王勃“关山难越，谁悲失路之人” |
| 崇高凌绝 | 仰止或登临俯瞰的胸襟 | 杜甫“会当凌绝顶，一览众山小” |
| 归隐静谧 | 喧嚣尽处的安顿之所 | 陶渊明“采菊东篱下，悠然见南山” |
| 恒久陪伴 | 人世散尽后的默然相对 | 李白“相看两不厌，只有敬亭山” |

### 云
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 自在超脱 | 无心出岫的闲适去留 | 陶渊明“云无心以出岫” |
| 漂泊无依 | 游子行迹不定 | 李白“浮云游子意，落日故人情” |
| 遮蔽阻隔 | 奸佞遮明或前路迷障 | 《古诗十九首》“浮云蔽白日” |

### 雨 / 霜 / 雪
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 细雨 / 夜雨 | 绵密幽思、促膝叙旧 | 秦观“无边丝雨细如愁”；李商隐“巴山夜雨涨秋池” |
| 朝雨 / 好雨 | 洗尘清润、惜别衬景 | 王维“渭城朝雨浥轻尘”；杜甫“润物细无声” |
| 霜 | 鬓发衰老、清寒孤警 | 张继“月落乌啼霜满天”；李白“不知明镜里，何处得秋霜” |
| 雪 | 孤绝清白、边塞壮丽 | 柳宗元“独钓寒江雪”；岑参“千树万树梨花开” |

### 黄昏 / 落日 / 秋色
| 意象指向 | 审美功能 | 名句例证 |
|---|---|---|
| 迟暮嗟老 | 美好将逝的怅惘 | 李商隐“夕阳无限好，只是近黄昏” |
| 天涯怀归 | 暮色催人思归 | 马致远“夕阳西下，断肠人在天涯” |
| 壮阔明朗 | 秋高气爽、不堕悲秋 | 王勃“秋水共长天一色”；刘禹锡“我言秋日胜春朝” |

## 二、草木花叶

| 意象 | 核心指向 | 翻新提示与名句 |
|---|---|---|
| **柳** | 送别留恋（谐音“留”）、春色摇曳 | “客舍青青柳色新”。送别不必硬折柳枝，可写柳絮拂衣或檐外青条 |
| **梅** | 孤标傲寒、清雅暗香 | 王安石“凌寒独自开”；林逋“疏影横斜水清浅，暗香浮动月黄昏” |
| **竹** | 虚心有节、风骨清响 | 苏轼“宁可食无肉，不可居无竹”；也可写风竹敲窗之声 |
| **菊** | 隐逸散淡、晚节傲霜 | 陶渊明“采菊东篱下”；郑思肖“宁可枝头抱香死” |
| **莲/荷** | 洁身自好、相思并蒂 | 周敦颐“出淤泥而不染”；《西洲曲》“低头弄莲子” |
| **梧桐** | 秋意初生、细雨孤凄 | 白居易“秋雨梧桐叶落时”；李清照“梧桐更兼细雨” |
| **松柏** | 岁寒后凋、坚贞长寿 | 《论语》“岁寒，然后知松柏之后凋也”；寿诗、言志常用 |
| **落花** | 春光暗逝、身世飘零 | 晏殊“无可奈何花落去”；李清照“花自飘零水自流” |

## 三、飞禽走兽与虫鱼

| 意象 | 核心指向 | 名句例证 |
|---|---|---|
| **鸿雁** | 远信、游子漂泊、秋声惊时 | 李清照“云中谁寄锦书来，雁字回时”；范仲淹“衡阳雁去无留意” |
| **杜鹃（子规）** | 思归（“不如归去”）、春晚哀切 | 秦观“杜鹃声里斜阳暮”。避免直套“啼血”，可写其夜啼声或林间影 |
| **猿** | 三峡羁旅、断肠凄清 | 杜甫“风急天高猿啸哀”；李白“两岸猿声啼不住” |
| **寒鸦** | 暮色荒寒、群栖反衬孤身 | 秦观“斜阳外，寒鸦万点，流水绕孤村” |
| **蝉** | 居高饮露（清高）、秋暮凄切 | 虞世南“居高声自远”；柳永“寒蝉凄切，对长亭晚” |
| **鸥鹭** | 忘机闲适、归隐江海 | 杜甫“飘飘何所似，天地一沙鸥”；黄庭坚“鸥盟” |
| **骏马** | 雄心万里、奔波羁旅或怀才 | 杜甫“骁腾有如此，万里可横行”；韩愈“千里马常有” |
| **鲲鹏** | 壮志凌云、高举超越 | 《庄子》“抟扶摇而上者九万里”；李白“大鹏一日同风起” |

## 四、器物、空间与人间烟火

| 意象 | 核心指向 | 名句与日常转化提示 |
|---|---|---|
| **灯 / 烛** | 深夜独守、寒夜暖意、聚散今昔 | 李商隐“何当共剪西窗烛”；今景可写街角昏灯、案头台灯 |
| **酒 / 盏** | 豪迈破愁、饯别劝饮、独酌孤怀 | 曹操“对酒当歌”；李白“举杯消愁愁更愁”；王维“劝君更尽一杯酒” |
| **舟 / 帆** | 身世浮沉、远行目送、江湖归隐 | 李白“孤帆远影碧空尽”；苏轼“小舟从此逝，江海寄余生” |
| **楼 / 台** | 登临望远、怀古苍茫、独守眺望 | 王之涣“更上一层楼”；晏殊“独上高楼，望尽天涯路” |
| **长亭 / 古道** | 行旅离别、风尘仆仆 | 李白“长亭更短亭”；今景可化用驿站、月台、长街 |
| **帘 / 窗** | 内外之隔、深闺或独处心境 | 李清照“帘卷西风，人比黄花瘦”；窗前光影极宜表现时间推移 |
| **镜 / 鬓** | 惊觉年华暗老、揽镜自审 | 李白“高堂明镜悲白发”；陆游“镜中衰鬓已先斑” |
| **棋 / 琴 / 书** | 雅集忘机、知音难遇、治学安身 | 刘禹锡“可以调素琴，阅金经”；高山流水（伯牙钟子期）喻知音 |
