# 立意与作诗手艺

立意决定“这首诗到底要说什么”，手艺决定“怎么把它写透、写活”。这两件事在动笔前后各司其职：**起草前用立意统摄全篇，一气写成后换编辑之眼用作法推敲。**

---

## 一、立意三层：立象 · 立意 · 立骨

### 1. 先写出一句话立意

动笔前，先在心里用一句大白话写下：“我想让读者读完后，感到／想到＿＿＿。”

- **好的立意**（具体、可感、有落点）：“深夜加班后，一碗路边馄饨让人觉得这座城市还是暖的。”“他钓了十年鱼，学会的是等。”
- **空的立意**（大而无当，贴到哪都能用）：“表达对生活的热爱。”“歌颂奋斗精神。”

### 2. 三重深度：事（景） → 情 → 理

| 层次 | 关注点 | 例子 |
|---|---|---|
| 事 / 景 | 看见了什么、发生了什么 | “白日依山尽，黄河入海流” |
| 情 | 这件事带来什么触动 | “独在异乡为异客，每逢佳节倍思亲” |
| 理 | 由此生发何种普适体悟 | “欲穷千里目，更上一层楼” |

- **多数好诗是由事入情，或由事入理。** 只有事无情是流水账；只有理无事是空洞说教。
- **不必强行拔高到“理”。** 记事、柔情诗停在“情”上最动人；言志、励志才需推向“理”或格局（从个人推向天地古今，但要从真实经历长出来）。

### 3. 从素材提炼立意与“立骨”

1. **优先采用用户给出的真实意象**（具体地名、物件、动作、对话），它比任何现成典故都珍贵。
2. **找最动人的切口**：往往不是宏大背景，而是一个反差或微小瞬间（如“老板娘多添一个蛋”，胜过“加班很苦”）。
3. **立骨定结构**：立意定好后，选择最能承托它的诗眼（落点）与体裁——瞬间之感用绝句，层层展开用律诗或词，奔涌长气用歌行。

### 4. 立意求新五法与类型对不上时

- **求新手段**：**翻案**（“自古逢秋悲寂寥，我言秋日胜春朝”）、**换视角**（对面落笔如《月夜》《九月九日忆山东兄弟》）、**以小见大**（借一盏灯写整座城）、**反常合道**、**旧意象入今景**（月、雁、柳落入早班车或写字楼）。求新不等于求怪；豪放一路尤重气象顺畅，不必刻意扭出小巧比喻。
- **不硬套类型**：多类混合（如“退休师长祝寿”兼祝颂、酬赠、定场）时，主类型定章法、他类借写法；完全不在 [../types/index.md](../types/index.md) 十二类中时，直接回到本节提炼一句话立意，自由选体裁。

## 二、意象与画面：具象 · 统一 · 互动

意象详见 [imagery.md](imagery.md)，运用时守住四条原则：

1. **具体胜于抽象**：用看得见、听得见、摸得着的物事动作（“檐角将落未落雨”），代替“美好”“沧桑”“辉煌”“正能量”等空泛大词。
2. **一首一主意象群**：绝句 1–2 个，律诗 2–3 个，中长调 3–5 个。杜甫《登高》以“落木（有限）”对“长江（无限）”贯通全篇；切忌月、酒、剑、花、梦、红尘轮番轰炸。
3. **景物要有互动，不做静物罗列**：避免名词或静态画面孤立并列（“寒鸦数点斜阳晚”只是两张静照），善用动词让意象彼此发生关系（“寒鸦点破苍山晚”）。温庭筠“鸡声茅店月，人迹板桥霜”虽名词并置，实以早行时间与体感暗线串联，不宜东施效颦。
4. **情感色彩一致**：除非刻意用“以乐景写哀，以哀景写乐”（王夫之语，如《采薇》“昔我往矣，杨柳依依”），否则不要前写“枯藤老树”、后接“桃花流水”。

## 三、章法与收尾

- **绝句（起承转合，重在第三句）**：起句交代时地或画面 → 承句顺势展开细节 → **转句**陡然换角度/时空/情绪/生出动作（如“欲穷千里目”）→ 合句收束留味。
- **律诗（起 → 展 → 转深 → 结穴）**：首联破题 → 颔联对仗展开（多写景或叙事，勿四言一法）→ 颈联对仗转深（由景入情、由近及远或由实转虚，避与颔联重意）→ 尾联结穴。
- **词（上下片分工，重在换头）**：或上景下情、或上今下昔，下片首句“换头/过片”须接住上片气脉又翻出一层（详见 [../forms/ci.md](../forms/ci.md)）。
- **古风与歌行（以气运辞）**：一韵段即一意群，每换韵即推进一步（详见 [../forms/guti.md](../forms/guti.md)）。
- **收尾八式**（避开空洞口号与总结前文）：
  - 以景结情（“唯见长江天际流”）、以问作结（“能饮一杯无”）、宕开一笔（跳向更大时空）、警句点题、以动作收（“更上一层楼”）、直抒胸臆（“直挂云帆济沧海”）、陡然收住（“与尔同销万古愁”）、末尾反转（苏轼《洗儿》）。

## 四、炼字、对仗与句法

- **动词即诗眼**：好动词胜过十个形容词。“春风又绿江南岸”（形作动）、“红杏枝头春意闹”、“星垂平野阔，月涌大江流”。推敲时在关键位（五言第三字、七言第五字）试换 3–5 个动词，求“不可替代”而非“生僻”。
- **虚词斡旋但勿滥用**：王维“空山不见人，但闻人语响”之“但”，杜甫“映阶碧草自春色，隔叶黄鹂空好音”之“自”“空”，柳宗元“独钓寒江雪”之“独”，皆能转出空间与心境。但绝句“空、独、自、唯”及文言助词“之乎者也矣焉哉”不宜滥用（绝句一般 ≤ 2 次，律诗 ≤ 4 次），以免油滑或酸腐。
- **对仗四忌**：忌**合掌**（“神州千古秀／赤县万年春”同义废话）；忌**词性或结构不相对**；忌**无意同字相对**；忌**四言一法**（颔联、颈联句法结构完全雷同，读来呆板，如两联全是“名+动+名+方所”）。工对、宽对、流水对、借对、当句对详见 [../forms/jinti.md](../forms/jinti.md)。
- **句法变化**：倒装（“香稻啄余鹦鹉粒”）、省略、时空跳跃、节奏重音（五言二三、七言四三）。

## 五、语言底线与避坑：戒白话腔、戒伪古词、戒套语

### 1. 淘汰现代白话腔（除非明确要打油或俚曲）

| 常见病灶 | 具体例子 | 古典化换法 |
|---|---|---|
| 现代动态/结构助词 | 了、着、的、地、得、吗、呢、吧 | 了 → 已/初/罢；着 → 犹/方/正 |
| 现代程度/逻辑副词 | 很、非常、特别、正在、已经、然后、因为 | 很 → 偏/殊/甚/绝；突然 → 忽/乍 |
| 现代口语与双音词 | 疲倦、温暖、感动、回家、下班、老板、点赞、心儿 | 疲倦 → 倦；回家 → 归；老板 → 店家/主人；不用儿化与网络语 |
| 模糊时间与空泛抒情 | “曾经”“有一天”“好美”“太棒了” | 昔/曩/畴昔/当年；一切情绪靠具体意象传达 |

### 2. 今语自然入诗，勿硬造“伪古词”

写当代生活（灯、车、屏、高楼、加班）时，**可用古今通用的本色词或天然雅称**（城市可用古称如长安、燕京、沪上、羊城；加班可用“伏案”“夜直”；鸡蛋可称“鸡子”），放在稳妥的节奏位上即可。**切忌**强行拼凑没人懂的伪古词（如把手机叫“掌上方寸”、把飞机叫“铁翼”，读者猜谜不如不写），也不要生造古籍无载的僵硬组合（如“幽月静花”）。

### 3. 常见高频套语排查表

一个词组如果在脑中浮现的是“到处见过的词块”而非“眼前具体画面”，就是套语，推敲时优先替换：

| 套语 | 病根 | 替换方向 |
|---|---|---|
| 独倚栏杆 / 凭栏 / 倚栏 | 宋元词用滥，无个体动作 | 具体姿势或视野：立尽斜阳 / 目断云山 / 扶栏 |
| 泪满襟 / 泪沾巾 | 直白干瘪，缺乏克制 | 留白细节：低头只道是汤烟 / 欲语还休 |
| 愁如海 / 愁似水 | 失去通感，修辞化石 | 具象质感：愁如啮 / 压枝欲折 / 客鬓暗添霜 |
| 梦断 / 肠断 | 空泛情绪标签 | 写梦醒时的具体声响或物象 |
| 红尘 / 沧桑 / 繁华落尽 / 岁月如歌 | 空泛大词，“老干部体”重灾区 | 换成眼前真实的一扇窗、一碗汤、一树叶 |
| 杜鹃啼血 / 浮生若梦 | 过度消费，极易滑成口头禅 | 不用熟套，或翻新角度（如写鸟飞之姿而非啼血） |

### 4. AI 写诗十大通病速查

1. **老干部体**（四平八稳、空洞口号，放哪都对）；2. **意象堆砌**；3. **陈词套语**；4. **现代白话腔**；5. **生造搭配与伪古词**；6. **拼贴原典**（成段搬运古人字句，注释长于诗）；7. **合掌与四言一法**；8. **凑字凑韵**（强塞“之/兮/也”或与文意无关的韵脚词）；9. **情与景断裂**（前纯写景、后突兀喊苦）；10. **平仄靠语感**（误把入声“白、国、竹、一、十”当平声）。

## 六、交稿前自检问题

1. 能用一句大白话说出这首作品的立意和情感落点吗？
2. 是否有主意象群（且景物间有呼应动作），无无关意象混入？
3. 是否有属于这一次情境的真实细节（人、物、动作、声色）与自己的句子？
4. 不看注释能大致读通吗？有转折吗？结尾是从前文自然长出来的吗？
5. 律诗颔颈二联是否对仗且无合掌、无“四言一法”？
6. 白话助词、口语词、陈词套语和过密虚词/叠词是否清理干净？
7. 所有用典是否“典必贴意”、出处核实无误？（详见 [yongdian.md](yongdian.md)）
8. `scripts/meter.py check` 与 `scripts/dupcheck.py` 结果如何？多音字是否按字义确认？跨韵部或今音听感提示是否需要微调？
