# 用典法则与出处查证

## 1. 为何用典

- **以少胜多**：一两字承载整段故事与情绪纵深（如“冯唐易老”）。
- **厚重与含蓄**：直说太露或太重时，借古人之事体面托出。
- **根本原则**：典故为立意服务，先立意后找典，切忌为了炫一个漂亮典故而硬凑全诗。**一个贴切的白描，永远胜过三个硬塞的典故。**

---

## 2. 六种用典手法

| 手法 | 做法 | 典范 |
|---|---|---|
| **明用** | 直接点出人名、地名或典事 | 辛弃疾“凭谁问：廉颇老矣，尚能饭否？” |
| **暗用** | 不点名而将典事融进句意，字面自通 | 王勃“物华天宝，龙光射牛斗之墟”（丰城剑气） |
| **化用** | 改其辞而存其意，铸成自己的句子 | 李白“大鹏一日同风起”化自《庄子》“抟扶摇而上者九万里” |
| **反用（翻案）** | 反用原典之意，最见个性新意 | 杜牧“卷土重来未可知”；王勃“酌贪泉而觉爽” |
| **叠用（合用）** | 一联内以两典对仗映衬 | 刘禹锡“怀旧空吟闻笛赋，到乡翻似烂柯人” |
| **以典自况** | 以古人或神话意象自比，典人合一 | 李白一生以大鹏自比 |

> 化用名句后，须运行 `python scripts/dupcheck.py` 检查，避免无意间连续 5 字以上照搬前人原句；有意保留原句作呼应时，应在注释中交代。

---

## 3. 用典用量参考

| 体裁与类型 | 建议用量 | 说明 |
|---|---|---|
| 记事诗、写景诗 | 0–1 处 | 贵真贵新，完全不用典往往更动人 |
| 绝句 | 0–2 处 | 二十余字容量有限，1 个深典已重 |
| 律诗 | 1–4 处 | 常置于颔、颈二联作典对 |
| 词 | 1–3 处 | 豪放词可多，婉约词宜少 |
| 定场诗、祝颂、赠诗 | 1–4 处 | 以贴合对象行业/性格的人物比附为主 |
| 骈文、序、赋 | 可较密集 | 几乎句句有典，但须句句切题，不用僻典 |
| 怀古、咏史 | 视篇幅而定 | 写史即用典，史实归属必准 |

## 4. 选典与“典必贴意”三步自检

选典需守五字诀：**切**（切题、切人——医用杏林、师用杏坛、江南莼鲈、塞外阳关）、**熟**（忌读死书式的生僻典）、**准**（不弄反典义褒贬）、**新**（熟典翻新）、**避忌**（婚诗避长门破镜，寿诗避薤露蒿里，送别慎用易水）。

**下笔用典前，必过“典必贴意”三步自检**：
1. **典的原语境与感情基调是什么？**
2. **本诗当前这一句的情感方向与之是否一致（或构成有意的反讽/反用）？**
3. **典的语义域是否过窄或错位？**

常见典意偏差警示：

| 容易误用的典/词 | 真实出处与原语境 | 常见误用 |
|---|---|---|
| 欧阳修“深深院” | 《蝶恋花》“庭院深深深几许”，写闺怨幽闭 | 误用于怀念美好过往，情感方向相悖 |
| 白居易“春宵短” | 《长恨歌》“春宵苦短日高起”，指帝妃洞房欢娱 | 语义域过窄，误用于普通恋情有越界感 |
| 李白“浮生若梦” | 《春夜宴从弟桃花园序》，旷达及时行乐 | 误用于日常小郁闷，格局错位 |
| 诗经“七月流火” | 《豳风·七月》，大火星西沉、天气转凉 | 误当盛夏酷暑 |
| 宋玉“空穴来风” | 《风赋》，原指有孔穴才有风，喻事出有因 | 误作毫无根据（当代语境亦多争议，入古典慎用） |
| 后汉书“差强人意” | 《吴汉传》，原指大体还能振奋人意 | 误作不满意 |
| “东床” / “结发” | “东床”指女婿；“结发”在婚诗指原配，李白诗指少年 | 不可张冠李戴 |

## 5. 两大用典范式

| | 太白式 | 滕王阁式 |
|---|---|---|
| 典源 | 《庄子》、楚辞、神话、游仙 | 史书、正史人物故事 |
| 密度 | 疏而大，一两核心意象贯通全篇 | 密而工，对仗叠用、几乎句句有来历 |
| 效果 | 浪漫飞扬、气象雄浑 | 典雅富丽、厚重端庄 |
| 适用 | 言志、意气风发、歌行、豪情 | 正式典礼序文、怀古、骈文、庄重定场诗 |

## 6. 原典查证流程与注释格式

需要用典但记忆不确时，**先查本地库，再联网原典互证，绝不编造出处**：

1. 先查 [allusions.md](allusions.md) 精选典故库。
2. 引用古人诗句先跑 `python scripts/dupcheck.py --find "片段"` 或 `--title "诗题"`。
3. 联网搜索时优先核对原典：**维基文库**（zh.wikisource.org）、**中国哲学书电子化计划**（ctext.org），字词参考**汉典**（zdic.net）；古诗文网、搜韵仅作线索，尽量互证。
4. 无法联网时，只用有把握的常见典，并在注释标注“出处凭记忆，建议核对”。查不到可靠出处的典故宁可弃用。

**典故注释格式**（无典则交付时直接省略“注释”一节）：

> 1. 扶摇：语出《庄子·逍遥游》“抟扶摇而上者九万里”，以大鹏乘风喻壮志凌云。
> 2. 龙光射牛斗：用《晋书·张华传》丰城剑气事，斗牛间常现紫气，喻才华终将显露。

要点：标出诗中对应字词 + 书名·篇名 + 简短原文（≤20字） + 一句话说明诗中取义；传说或归属存疑处如实标“相传”“一说”。
